# PLANS.md

> 변경 영향이 큰 작업의 계획서.
> AI 에이전트가 코드 작성 전 본 문서에 계획을 기록하고, 사람 리뷰 후 실행한다.
> 작은 변경(50줄 미만 리팩터 등)은 본 문서를 거치지 않고 곧장 작업해도 됨.

> 📝 **상태**: 사용 시 작성 시작

---

## 📝 사용 가이드

**언제 PLANS.md를 거치나?**
- 새 기능 추가 (큰 단위)
- 아키텍처 변경
- DB 스키마 변경
- AI 프롬프트 변경
- 외부 의존성 추가

**거치지 않아도 되는 작은 변경:**
- 변수명 리팩터
- 작은 버그 수정
- 문서 오타 수정
- 테스트 추가

---

## 사용 흐름

1. AI 에이전트가 큰 작업을 픽업
2. 본 문서에 계획 작성 (아래 템플릿 사용)
3. 사람 리뷰 & 승인
4. 승인 후 → `docs/exec-plans/active/`로 분할 이동
5. 작업 완료 후 → `docs/exec-plans/completed/`

---

```markdown
2. [구체적 단계 2]

### 예상 소요 시간
[몇 시간 / 며칠]
```
