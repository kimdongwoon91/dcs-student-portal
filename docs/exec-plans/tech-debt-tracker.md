# Tech Debt Tracker

> 기술 부채 추적. AI 에이전트가 작업 중 발견한 부채를 본 문서에 기록한다.
> 주기적으로 리뷰하여 `active/`에 작업 카드로 분할 이동시킨다.

> 📝 **상태**: 빈 상태로 시작 (작업이 진행되며 채워진다)

---

## 형식

```
- [ ] [Priority: High/Med/Low] [YYYY-MM-DD] 부채 설명
      발견자: AI / 사람
      영향: ...
      해결 제안: ...
```

---

## 활성 부채 목록

(없음 - 작업 시작 후 발견되는 부채를 여기에 기록)

---

## 처리 흐름

1. AI 작업 중 부채 발견 → 본 문서에 기록
2. 주기적 리뷰 (주 1회 권장) → `active/`로 카드 생성
3. 작업 완료 → 본 문서의 해당 항목 삭제 + 카드를 `completed/`로

---

## Document Updates

- YYYY-MM-DD: 템플릿에서 복사·초기화
