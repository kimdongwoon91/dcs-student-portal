---

## 1. Vision

> "대전도시과학고 학생이 자신의 성장 데이터를 언제 어디서든 한눈에 확인하고, 선생님과 자연스럽게 연결될 수 있도록 돕는다."

---

## 2. Target User

**대전도시과학고 재학생 (모바일 우선 사용자)**

- 본인의 평가 결과·생기부·프로젝트 활동을 궁금해하는 학생
- 담임/전문 교사에게 상담 신청을 쉽게 하고 싶은 학생
- 학교 포털보다 빠르고 깔끔한 모바일 UX를 원하는 학생

---

## 3. Core Problem

- 학교 행정 시스템은 모바일 UX가 불편하고 정보가 흩어져 있음
- 학생이 본인의 성취도·피드백을 실시간으로 확인할 수 없음
- 상담 신청 절차가 복잡하거나 선생님께 직접 말하기 어색함

---

## 4. Value Proposition

**노션(교사 관리 데이터) + Supabase(학생 계정) = 학생 전용 모바일 포털**

- 핵심 차별점: 교사가 노션에 입력하면 학생 앱에 즉시 반영
- 실명 비표시 원칙으로 학생 프라이버시 보호
- 상담 신청을 탭 한 번으로 — 접수 확인까지 인앱 알림

---

## 5. Non-Goals

| 안 하는 것 | 이유 |
|---|---|
| ❌ 교사용 관리 화면 | 노션이 이미 교사 UI; 중복 개발 불필요 |
| ❌ 석차·등수 표시 | core-beliefs 위반; 비교 문화 조장 |
| ❌ 학부모 계정 | 1차 범위 밖; 복잡도 급증 |
| ❌ 실시간 채팅 | 상담 신청 바텀시트로 충분 |
| ❌ 결제·BM | 학교 내부 서비스; 무료 운영 |

---

## 6. Business Model Note

- 모델 유형: 무료 (학교 내부 서비스)
- 비용: Vercel 무료 티어 + Supabase 무료 티어 + 노션 API 무료 한도 내

---

## 7. Success Metrics

| 우선순위 | 지표 | 의미 |
|:---:|---|---|
| ⭐ | **월간 활성 학생 비율** | 전교생 중 월 1회 이상 접속한 학생 % |
| 2 | **상담 신청 건수** | 포털을 통한 상담 접수 증가율 |
| 3 | **평가 확인 후 피드백 조회율** | 성취도 확인 → 피드백까지 보는 비율 |

**의도적으로 추적하지 않는 지표:**
- DAU/세션 수 — 학교 포털은 "필요할 때만" 쓰는 것이 정상
