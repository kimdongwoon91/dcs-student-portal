## 1. Visual Identity

### 1.1 Color System (CSS 변수)

| Role | Token | Hex | 사용처 |
|---|---|---|---|
| Background | `--bg` | `#EEF2F7` | 페이지 배경 |
| Card | `--card` | `#FFFFFF` | 카드, 바텀시트 |
| Ink (text) | `--ink` | `#0E1B2C` | 본문 텍스트 |
| Primary | `--primary` | `#FF6A2B` | CTA, 강조, 게이지 |
| Blue | `--blue` | `#2B6FFF` | 정보, 링크, 성취 배지 |
| Green | `--green` | `#16A06A` | 완료, 합격, 긍정 상태 |
| Amber | `--amber` | `#E0A100` | 주의, 진행 중 |
| Red | `--red` | `#E2483B` | 오류, 경고, 상담 필요 |
| Radius | `--radius` | `18px` | 카드, 버튼 |

### 1.2 Typography

| Use | Font | Weight |
|---|---|---|
| 전체 | Pretendard (CDN) | 400, 600, 800 |
| 숫자 큰 강조 | Pretendard | 800 |
| 본문 | Pretendard | 400, 600 |

**Type Scale**
- Display (환산총점): 56px / 800
- H1: 22px / 700
- H2: 18px / 600
- Body: 15px / 400
- Caption: 13px / 400

### 1.3 시그니처 컴포넌트

홈 화면: 환산총점 큰 숫자(56px/800) + 등급 pill(`--primary` 배경) + 게이지 트랙(`--primary`)

## 2. Voice & Tone

### 2.1 인칭
- ✅ "(닉네임)님" — 항상 닉네임 사용
- 🚫 실명, 학번, "학생" 단독 호칭

### 2.2 이모지 정책
- ✅ 알림 🔔, 상담 신청 완료 ✅ 같은 핵심 상태 전달에만
- 🚫 장식용 이모지 남발 금지

### 2.3 문장 구조
- 짧고 명확. 한 줄이면 충분한 걸 두 줄로 쓰지 않음
- 에러: "무엇이 잘못됐고 어떻게 하면 되는지" 2문장

### 2.4 금지 표현 (core-beliefs 위반)
- 🚫 "전교 N등", "반에서 X번째"
- 🚫 "평균 이하", "하위 XX%"
- 🚫 실명 호칭

### 2.5 권장 표현
- ⭕ "(닉네임)님의 이번 환산총점은 XX점이에요"
- ⭕ "지난 평가보다 향상됐어요"
- ⭕ "선생님 피드백이 도착했어요 🔔"

## 3. 핵심 콘텐츠 출력 포맷

- **카드형**: 각 영역(평가·성장·활동·상담)을 독립 카드로 분절
- **탭 하단 내비게이션**: 홈·평가·성장·활동·상담 5탭
- **바텀시트**: 상담 신청 폼
- **모바일 전용**: max-width 480px, 중앙 정렬

## 4. UX Flow Philosophy

### 4.1 온보딩
- ✅ 회원가입 → 즉시 홈 진입 (별도 튜토리얼 없음)
- 🚫 온보딩 슬라이드 스킵

### 4.2 CTA 톤
- ✅ "상담 신청하기", "확인하기" — 동사형 명확
- 🚫 "지금 바로!", "놓치지 마세요" 같은 압박형

### 4.3 에러 메시지
- ✅ "이름 또는 비밀번호가 맞지 않아요. 다시 확인해주세요."
- 🚫 기술적 에러코드 노출, "Internal Server Error"

### 4.4 로딩
- ✅ 스켈레톤 카드 (데이터 구조 미리 보여줌)
- 🚫 빈 화면에서 스피너만
